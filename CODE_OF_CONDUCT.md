# Code of conduct

mdstack adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone in every project space:
issues, pull requests, reviews, discussions and any other channel the
project uses, and to the crew's bot accounts and the people who run them.

## In short

- Be respectful and assume good faith; critique work, not people.
- No harassment, insults, personal attacks, sexualized language or imagery,
  or publishing anyone's private information without their permission.
- Accept the maintainers' decisions on moderation.

## Reporting

Report conduct concerns privately to the maintainers through the contact
listed on the repository owner's GitHub profile. Content on GitHub can also
be reported to GitHub with its **Report content** option. Do not use the
security route for conduct reports, or a public issue for either.

The maintainers review every report promptly and fairly, keep the
reporter's identity private, and may remove content or restrict
participation, following the Covenant's enforcement guidelines.
