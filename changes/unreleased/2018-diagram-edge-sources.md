Diagram edge-source rule: `docs/diagrams/README.md` now requires every canonical diagram to keep an edge table beside it, each edge citing the code or doc anchor it depicts (the deployment diagram's E1–E23 table is the example), and the review of a diagram change to compare every edge of that diagram, not only the changed ones, with its anchor. A lesson records the #2001 diagram, whose spawn and merge-ok edges contradicted their sources, with status `applied`.
