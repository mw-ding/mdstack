Configuration guide: new `docs/guides/configuration.md` walks through configuring a crew by task (which file an owner command reads and how to check it with `resolve`, identities, engines and tiers, one-repo versus team-file repo selection with `--repo`, concurrency and speed, and the rigor flavor), linking `docs/profile.md`, `docs/configuration/runtime-options.md`, `docs/configuration/team-files.md` and `docs/flavors.md` for every key. It keeps speed and caps apart from review flavor, separates the flavor's round caps from concurrency caps, and says a deployment's own light, normal or full-speed presets are its preferences, not product defaults. The docs index, the getting-started "Next" list and the guides manifest row link it.
